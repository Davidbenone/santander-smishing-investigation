# Evidence handling

No original PCAPs, unredacted SMS screenshots, cookies or session tokens are published here.

Before adding screenshots or excerpts:

1. Review for personal identifiers, phone numbers, cookies, tokens and unrelated traffic.
2. Redact sensitive fields without obscuring the evidence supporting the claim.
3. Keep original evidence in private storage and calculate SHA-256 hashes.
4. Record the capture time, interface, collection method and relevant filters.
5. Label each observation accurately; do not present unverified hypotheses as findings.

Potential future exhibits: redacted Firefox warning, 403 response, DNS exchange, HTTP redirect and laboratory topology.
